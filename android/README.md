# کبوتر برای اندروید

یک اپ اندروید سبک که فقط به سرور کبوتر شما وصل می‌شود (پیش‌فرض: `https://kabootar.up.railway.app`).
دوربین و میکروفون (تماس، ویس، پیام ویدیویی)، انتخاب فایل، دانلود، دکمه‌ی برگشت و لینک‌های دعوت داخل خود اپ کار می‌کنند.

## ساخت APK بدون نصب چیزی (GitHub Actions)
1. پروژه را در یک مخزن GitHub بگذارید (همان مخزنی که Railway از آن دیپلوی می‌کند).
2. تب **Actions** ← **Android APK** ← **Run workflow** (اگر آدرس سرورتان فرق دارد، اینجا بنویسید).
3. بعد از چند دقیقه، در همان اجرا بخش **Artifacts** ← `kabootar-apk` را دانلود کنید، از حالت zip درآورید و APK را روی گوشی نصب کنید.

## ساخت با Android Studio
پوشه‌ی `android` را باز کنید و ▶ Run بزنید. آدرس سرور در `android/gradle.properties` (`kabootarUrl`) است.

## نسخه‌ی ۳.۹: بخش‌های اندرویدی
- **انیمیشن شروع:** آیکون گرد کبوتر نرم وسط صفحه میاد و بعد اپ باز می‌شه (رنگش با تم روز/شب یکیه).
- **نوار بالا و پایین گوشی:** رنگشون با صفحه عوض می‌شه؛ استوری، عکس و دوربین مشکی.
- **اعلان‌ها با اپ بسته:** یه اتصال سبک به سرور خودتون (بدون سرویس گوگل). پاسخ و «خوانده شد» از خود اعلان.
  اگه گوشی اعلان‌ها رو دیر می‌ده: تنظیمات ← اعلان‌ها ← «بهینه‌سازی باتری» رو خاموش کنید.
- **گالری داخل اپ:** هم در پیوست، هم در استوری.
