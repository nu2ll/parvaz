# 🕊️ کبوتر (Kabootar) v2

پیام‌رسان کامل **به سبک تلگرام**: سرور + وب‌کلاینت، از صفر، با **Node.js و صفر وابستگی** (نه `npm install`، نه پکیج).
REST API + WebSocket لحظه‌ای + SQLite داخلی Node + آپلود فایل + رابط کاربری فارسی و راست‌به‌چپ با تم روشن و شب.

> این پروژه هیچ کدی از تلگرام ندارد و از MTProto استفاده نمی‌کند؛ فقط تجربه‌ی کاربری‌اش شبیه است.

**لحظه‌ای:** در حال نوشتن / ضبط صدا / ارسال فایل · ✓ و ✓✓ خوانده‌شدن · آنلاین و آخرین بازدید · شمارنده‌ی بازدید کانال · چند دستگاه همزمان · اتصال مجدد خودکار و همگام‌سازی

## اجرا
نیاز: **Node.js 22.13+**
```bash
node server.js        # http://localhost:8080
npm test              # ۸۶ تست سرور + ۴۸ تست رابط کاربری
```

## 🚀 دیپلوی روی Railway (فقط با GitHub)
1. محتوای این پوشه را در یک ریپوی GitHub بگذار.
2. در railway.com: **New Project ← Deploy from GitHub repo**.
3. **Settings ← Networking ← Generate Domain**.
4. روی سرویس **Attach Volume** با مسیر `/data` (تا پیام‌ها و فایل‌ها با هر دیپلوی پاک نشوند).

هیچ متغیری لازم نیست؛ سرور خودش Railway را تشخیص می‌دهد. هر `git push` = دیپلوی خودکار. ضبط صدا فقط روی HTTPS کار می‌کند (Railway خودش HTTPS می‌دهد).

### متغیرهای اختیاری
| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `PORT` | `8080` | پورت |
| `DB_PATH` | `./data/chat.db` یا داخل Volume | دیتابیس |
| `UPLOADS_DIR` | کنار دیتابیس | فایل‌های آپلودی |
| `MAX_UPLOAD_MB` | `50` | حداکثر حجم فایل |
| `SESSION_TTL_DAYS` | `60` | عمر نشست |
| `ALLOWED_ORIGINS` | روی Railway خودکار | اگر دامنه‌ی شخصی وصل کردی |
| `TRUST_PROXY` | روی Railway خودکار | پشت nginx بگذار `1` |

## ساختار
```
server.js            HTTP، فایل‌های استاتیک، هدرهای امنیتی
src/service.js       منطق چت (مشترک بین REST و WebSocket)
src/db.js            اسکیمای SQLite
src/files.js         آپلود و سرو فایل با Range
src/ws.js            WebSocket از صفر (RFC 6455)
src/realtime.js      گیت‌وی لحظه‌ای
src/routes.js        REST API
public/js/           وب‌کلاینت (core, ui, render, app, panels)
test/smoke.js        تست end-to-end سرور
test/ui.js           اجرای کلاینت واقعی روی سرور واقعی با DOM ساختگی
```

## امنیت
scrypt برای رمز · توکن ۲۵۶ بیتی که فقط هشش ذخیره می‌شود · rate limit · CSP سخت‌گیرانه بدون اسکریپت inline · همه‌ی محتوا با textContent رندر می‌شود (ضد XSS) · فایل‌های غیررسانه‌ای همیشه دانلود می‌شوند و با `sandbox` سرو می‌شوند · غیرعضوها 404 می‌گیرند.
**محدودیت:** رمزنگاری سرتاسری ندارد؛ پیام‌ها روی سرور خوانا هستند. تماس صوتی/تصویری، استوری و استیکرپک هم هنوز نیست.
